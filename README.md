# Q-Learning Grid World Navigation

A small, runnable reinforcement-learning project using only the Python standard library. An agent learns navigation from transition rewards on two obstacle maps or a custom ASCII map. A separate breadth-first search (BFS) checks whether the learned route is shortest. BFS never supplies actions, Q-values or training targets.

## Quick start

Requires Python 3.10+; no packages, credentials or datasets to install. Run commands from this repository directory:

```bash
python3 main.py --episodes 3000 --seed 42 --svg-dir outputs/svg
python3 -m unittest discover -v
```

The first command prints the learned policy, writes `results.json`, and saves two SVGs under `outputs/svg/`. Open the SVGs in a browser: the policy shows the actual greedy rollout over learned action arrows; the learning curve shows trailing mean training return. On the default map, the seed-42 run reaches the goal in eight moves, matching BFS. A GitHub Actions workflow runs the unit tests and a two-map training/evaluation smoke check on Python 3.12 after a push or pull request.

## Reproduce the measured experiment

```bash
python3 main.py --all-maps --seeds 0,1,2,3,4 --episodes 3000 --output outputs/benchmark.json --summary examples/metrics.json --svg-dir outputs/svg
```

The committed [metrics example](examples/metrics.json) was generated by this command with Python 3.14.4. Each map is trained from scratch for each of the five seeds, with a fresh zero-initialized Q-table. The seeds are fixed for the experiment, not selected from successful runs.

| Map | Size | Independent training runs | Greedy goals reached | Learned moves in each run | BFS shortest moves |
| --- | --- | --- | --- | --- | --- |
| classic | 5 × 5 | 5 | 5/5 | 8 | 8 |
| detour | 7 × 7 | 5 | 5/5 | 22 | 22 |

All ten learned routes match BFS, and the final 100 training episodes succeeded in every recorded run. `greedy_success` evaluates the final Q-table without exploration. `training_success_rate_last_100` instead describes training episodes, which still include exploration. Failed evaluations record `learned_path_steps: null`, rather than treating a partial route as a successful path.

These are measurements on ten small, deterministic, fully observed grid experiments. They do not establish performance on unseen layouts, noisy movement, real robots or arbitrary seeds. BFS solves this known graph directly; its role here is a correctness baseline, not a method Q-learning is claimed to outperform.

## Change the map

Choose the larger built-in map:

```bash
python3 main.py --map detour --seed 42 --svg-dir outputs/detour
```

Or use the included rectangular example:

```bash
python3 main.py --map-file maps/example.txt --episodes 3000 --seed 42 --output outputs/custom.json --svg-dir outputs/custom
```

The supplied custom-map run learns a 14-move path, equal to BFS. Edit or copy `maps/example.txt`: `S` is the single start, `G` the single goal, `#` a wall, and `.` a free cell. Rows must have equal lengths. The CLI rejects malformed or unreachable maps before training. Larger or more difficult layouts may need more episodes or a larger `--max-steps` cap; no success is guaranteed by the program.

Use `python3 main.py --help` for all options. `--seeds` overrides `--seed`; `--all-maps` runs both built-in maps and cannot be combined with `--map-file`.

## Method

States are `(row, column)` positions. Actions are up, right, down and left. Walls and boundary collisions leave the agent in place. Every episode starts at `S` and ends at `G` or after 150 actions by default.

| Setting | Value |
| --- | --- |
| Q-table initialization | All zero |
| Learning rate α | 0.2 |
| Discount γ | 0.95 |
| Exploration ε | Linear decay from 1 to 0.05 over the first 80% of episodes, then 0.05 |
| Goal reward | +100 |
| Valid nonterminal move | −1 |
| Wall or boundary collision | −5 |

The update is `Q(s,a) ← Q(s,a) + α × [reward + γ × max Q(next_state) − Q(s,a)]`; terminal transitions omit the discounted next-state term. A local seeded random generator controls epsilon-greedy exploration. Greedy ties use the fixed action order above. Evaluation stops on a repeated state or after at most the number of free cells, so a stuck policy cannot loop indefinitely. The learned start-to-goal path is calculated from Q-values, not from BFS or a stored route.

## Output and files

- `main.py`: map validation, environment, training, BFS baseline, greedy evaluation, CLI and standard-library SVG generation.
- `test_main.py`: nine tests covering transitions, invalid maps, known BFS routes, deterministic training, actual learned paths, loop handling and valid SVG output.
- `maps/example.txt`: editable custom map.
- `examples/metrics.json`: compact, actual benchmark results intended for version control.
- `results.json` or `--output`: detailed per-run Q-values, episode rewards/steps/successes, rollout paths and the summary.
- `outputs/`: generated results and optional SVGs, excluded by `.gitignore` along with Python caches.

This repository is an educational simulation. It demonstrates tabular reinforcement learning and reproducible evaluation, rather than a deployed autonomous navigation system.
